# Xin Lab 22기 - 공개 일정 페이지

이 저장소는 **일정(행사·학위일정)은 실데이터로 공개하되, 개인정보·금전 데이터는 절대 포함하지 않는** GitHub Pages용 저장소입니다.

**이 앱은 백엔드가 없는 완전 정적 페이지입니다.** 데이터가 `<script id="state-data">` 안에 HTML 그대로 박혀 있어서, "페이지가 공개면 그 안의 JSON도 전부 공개"입니다 (view-source나 curl로 그대로 보임). 그래서 항목별로 반드시 지켜야 하는 규칙:

| 필드 | 공개 저장소(`docs/`)에 포함 | 이유 |
|---|---|---|
| `events`, `eventTypes` | ✅ 실데이터 그대로 | 행사 제목·날짜·체크리스트, 개인정보 없음 |
| `degreeMilestones` | ✅ 실데이터 그대로 | 기수 전체 학위 일정, 개인 식별 정보 없음 |
| `members` | ❌ 항상 `[]` | 실명·전화번호 |
| `rsvps` | ❌ 항상 `{}` | 실명·전화번호·개인 응답 |
| `ledger` | ❌ 항상 `[]` | 계좌 잔액 등 금전 정보 |

- 실제 서비스(쓰기 가능): Claude 아티팩트 (비공개, 22기 멤버에게만 공유)
- 전체 실데이터 백업/버전관리: 별도 비공개 저장소 (`heen1987-ops/Xin-Lab-22`)
- 이 저장소: 위 표대로 스크러빙한 상태를 `docs/index.html`로 GitHub Pages 서빙

`docs/`를 갱신할 때마다 위 표의 스크러빙 규칙을 다시 확인하세요 — 특히 `members`/`rsvps`/`ledger`는 절대 실데이터가 들어가면 안 됩니다.
